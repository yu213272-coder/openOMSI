# 开发诊断日志

使用本次诊断版引擎、更新后的 `autopilot.osc` / `varlist.txt` 和 Lua 插件。

`faraway-autopilot.log` 自动创建在 `openomsi.exe` 旁边，追加写入，每次进程启动有新的 session 标记。普通启动每 250 ms 记录连续数据，按键、导航拒绝原因变化、状态变化和首次故障立即记录。

需要每一帧的全部记录时，将 `start-autopilot-debug.cmd` 放在 `openomsi.exe` 旁边并双击启动。它设置 `FARAWAY_AP_TRACE_EVERY_FRAME=1`，无需再次编译。每帧日志会明显增大文件，并可能降低帧率。

日志频道：

- `KEY`：按键按下/释放、脚本 trigger 是否存在、触发前所有车辆状态。
- `TICK_GATE`：是否暂停、脚下地图地面是否加载，是否允许执行玩家更新。
- `NAV`：任务、路线完整性/临时路线/回归路线标记、地图网络状态、路线 key 和 progress、当前投影窗口及车道 key、三维距离和横向偏移、朝向差、站点位置/方向/投影、前视道路接缝、转向曲率和目标速度、最终 ACCEPT 或 REJECT。
- `CONTROL`：本帧 dt、OSC 前后状态、实际交给物理系统的油门/刹车/转向/离合、键盘输入、手柄输入、OSC 命令、门叶和门目标、站点/驻车制动、挡位、电源、发动机、驱动力矩和前轴制动力。
- `FAULT`：首次发生的人工刹车、导航无效或 OSC 锁存故障，附当时完整快照。

导航拒绝码：1 联机；2 无时刻表任务；3 行程结束；4 无导航器；5 路线完整性/临时/回归/全图网络检查未通过（看同一条日志的 flags）；6 路线 key 与任务不匹配；7 空路线；8 无后续站点；9 站点位置未知；10 车辆投影失败；11 车道投影失败；12 到车道的三维距离超过 2m；13 朝向差超过 45 度；14 站点在 12m 范围内投影失败；15 站点投影落在已通过的路线段；16 道路接缝超过 1.5m；17 前视目标在后轴后方；18 转向曲率参数无效；19 输出非有限数。0 表示导航接受。

故障码：101 人工刹车触发优先权；102 开启条件未通过；103 运行中导航/电源/发动机/挡位/驻车/倒行等条件未通过；104 站点超过 2m；105 开门阶段车辆发生运动；106 行驶或离站阶段车门/站点制动联锁触发。原始变量记录用于进一步区分组合条件，故障码不是对地图问题的自动定论。

复现方法：启动单人游戏，加载本车及任务，等待路线加载，记录一次“开自动后不走”的操作，然后退出游戏并提供 `faraway-autopilot.log`。不要先删除故障，再开始录日志，以免丢失最初触发点。

日志可能包含本机文件/地图/站点信息。对外公开前应检查和脱敏；排查时可直接提供本地日志。本插件只读变量，不设置油门、刹车或故障，不自动解除任何联锁。
